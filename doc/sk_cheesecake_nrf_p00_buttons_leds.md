# SK CheeseCake NRF P00 按键与灯效说明

本文面向使用 `sk_cheesecake_nrf_p00` 板子的普通使用者，整理当前项目里已经实现的按键和状态灯行为。

适用范围：

- 主要适用于 `sk_cheesecake_nrf_p00/nrf52840/uf2` 固件。
- `dev` 变体使用同一套按键和灯效硬件定义，但没有 UF2 输出，默认状态灯颜色也不同。
- 当前工程的全局配置启用了 `CONFIG_USER_EXTRA_ACTIONS=y`，因此下文包含多次短按动作。

## 硬件位置

| 名称 | 固件别名 | 引脚 | 当前用途 |
| --- | --- | --- | --- |
| User button 1 | `sw0` | P1.10，低电平按下，内部上拉 | 主用户按键；支持开机、重启、关机、校准、重新配对、进入 DFU |
| User button 2 | `sw1` | P0.13，低电平按下，内部上拉 | 长按启动主动温度校准（Heated T-Cal） |
| RGB 状态灯 | `led-strip` | I2S0 驱动，1 颗 WS2812/兼容灯珠 | 显示启动、运行、充电、错误、配对、校准等状态 |
| LED 电源使能 | `led-en-gpios` | P1.06，高电平开启 | 固件会在需要显示灯效时打开，不需要显示时关闭以省电 |

UF2 固件当前默认状态色为偏粉红色：`R=10000, G=3137, B=5294`。全局亮度为 `1000/10000`，也就是约 10% 亮度。

## 按键操作

常规电源、配对和 DFU 操作使用 `sw0 / User button 1`；主动温度校准使用 `sw1 / User button 2`。

| 操作 | 触发方式 | 结果 |
| --- | --- | --- |
| 开机/唤醒 | 关机状态下按下 `sw0` | 唤醒设备并继续启动，启动时会看到开机灯效 |
| 重启 | 快速短按 1 次，随后等待约 1 秒 | 设备重启；测试模式下该动作会被阻止 |
| ZRO 零偏校准 | 快速短按 2 次，随后等待约 1 秒 | 开始主 IMU 加速度计/陀螺仪零偏校准；校准时请把设备静置在稳定表面 |
| 重新配对 | 快速短按 3 次，随后等待约 1 秒 | 重置当前运行中的配对状态并进入重新配对流程 |
| 进入 UF2 DFU | 快速短按 4 次或 5 次，随后等待约 1 秒 | 重启进入 UF2 bootloader，可通过 USB 拖拽/刷入 UF2 固件 |
| 保留/无动作 | 快速短按 6 次或 7 次 | 当前 SK CheeseCake NRF P00 构建没有绑定动作 |
| 进入 OTA DFU | 快速短按 8 次或 9 次，随后等待约 1 秒 | 设置 OTA DFU 启动标记并重启；需要对应 bootloader/SoftDevice 支持 |
| 关机 | 长按约 1 秒 | 播放关机灯效并请求系统关机 |
| 取消长按关机 | 触发关机后继续按住，总按住约 5 秒 | 当前多按键动作构建中会取消关机；不会重置配对 |
| USB 连接时进 DFU | 按住 `sw0` 的同时接入 USB/启动 USB 控制台 | 重启进入 UF2 DFU bootloader |
| 主动温度校准 | 连续按住 `sw1` 约 3 秒 | 使用配置的默认目标温度启动 Heated T-Cal，当前默认目标为 44°C；必须接入外部电源 |

`sw0` 短按会在最后一次按下后的约 1 秒统一结算，每次有效按压需要超过约 50 ms。`sw1` 按住不足 3 秒不会触发功能；达到阈值后每次按住只触发一次，必须释放后才能再次触发。主动温度校准已经运行时，再次长按只会被忽略。进行 ESB OTA 或 OTA 抑制期间，本地按键动作会被阻止，状态灯会给出“进度/已收到”的提示灯效。

“重新配对”是运行时重新进入配对流程；成功配上新接收器后会写入新的配对信息。如果需要明确清除保存的配对数据，请使用控制台的 `clear` 命令。

## 状态灯颜色

| 颜色类别 | 视觉含义 |
| --- | --- |
| 默认色 | 正常运行、启动、普通提示；UF2 当前为偏粉红色 |
| 绿色 | 成功、完成、已充满 |
| 红色 | 错误 |
| 橙色/琥珀色 | 充电、外部供电、低电量 |
| 蓝色 | 配对 |
| 青色→橙红色渐变 | T-cal、温度加热流程，按温度从低到高渐变 |
| 红色→绿色渐变 | 磁力计校准流程中，按完成度从低到高渐变 |
| 紫色 | 调试或开环温度校准加热状态 |

如果多个状态同时存在，灯效按优先级显示：按键/启动/关机最高，其次是传感器校准、连接/配对、错误状态，最后才是日常运行/充电状态。因此校准或错误灯效可能暂时覆盖充电呼吸灯。

## 常见灯效

| 灯效 | 表现 | 常见含义 |
| --- | --- | --- |
| 常亮 | 固定亮起 | 按键按下、正在采样/忙碌 |
| 短闪 | 亮约 100 ms，灭约 900 ms | 等待配对 |
| 慢闪 | 亮约 500 ms，灭约 500 ms | 等待、长按提示、等待设备静止 |
| 快闪 | 约 200 ms 间隔闪烁 | 已准备好，等待下一步操作 |
| 慢呼吸 | 约 5 秒周期渐亮渐灭 | 充电、温度校准升温 |
| 快呼吸 | 约 2 秒周期渐亮渐灭 | 温度校准保温/稳定阶段 |
| 开机提示 | 默认色短闪 3 次 | 从关机/唤醒进入固件 |
| 关机提示 | 短暂停顿后渐灭 | 正在关机 |
| 进度提示 | 绿色短闪 2 次 | 按键动作被 OTA 阻止、单步进度、磁力计校准还需要继续转动 |
| 完成提示 | 绿色短闪 4 次 | 配对成功、校准完成 |
| Ping 提示 | 默认色短闪 10 次 | 控制台/远端 ping 设备 |
| 错误提示 | 红色快速闪 3 次 | 一次性错误提示 |

## 运行与电源状态

| 状态 | 灯效 |
| --- | --- |
| 正常运行 | 默认色每 10 秒短亮约 300 ms |
| 正在充电 | 橙色慢呼吸 |
| USB 或外部电源接入，但未读到独立充电脚 | 橙色慢呼吸 |
| 低电量 | 橙色慢闪 |
| 已充满 | 固件支持绿色低亮常亮，但当前 SK CheeseCake NRF P00 设备树没有定义 `stby-gpios`，通常不会出现独立“已充满”灯效 |
| 关机/休眠后 | 状态灯关闭，LED 供电也会关闭 |

当前设备树定义了 `chg-gpios` 充电状态脚；`plug-gpios` 目前主要用于电源诊断日志。固件还会通过 USB VBUS 和电池电压推断外部供电状态。

## 配对与连接状态

| 状态 | 灯效 |
| --- | --- |
| 未配对/等待接收器 | 蓝色短闪 |
| 配对成功 | 绿色短闪 4 次 |
| 连接错误 | 红色 3 连闪，每约 5 秒循环一次 |
| 长时间无法连接 | 连接错误持续超过当前配置的 3 分钟后，固件会请求关机 |

如果设备刚刷机或配对被重置，它会进入配对模式。请让接收器处于可配对状态，直到看到完成提示。

## 错误灯效

| 错误类型 | 灯效 |
| --- | --- |
| 传感器通信错误 | 红色 2 连闪，每约 5 秒循环一次 |
| 连接错误 | 红色 3 连闪，每约 5 秒循环一次 |
| 系统错误 | 红色 4 连闪，每约 5 秒循环一次 |
| 通用持续错误 | 红色 500 ms 亮/灭循环 |

多个错误同时存在时，固件会轮流显示这些错误组。

## 校准灯效

| 校准流程 | 灯效与含义 |
| --- | --- |
| ZRO 零偏校准 | 慢闪表示等待设备静止；常亮表示正在采样；绿色 4 闪表示完成；失败时校准灯效关闭并保留旧校准 |
| 六面/多姿态加速度计校准 | 慢闪表示等待稳定姿态；常亮表示正在记录当前姿态；绿色 2 闪表示当前姿态已保存；快闪提示姿态重复或已准备继续 |
| 磁力计校准 | 先慢闪约 2 秒用于识别设备，再绿色 2 闪表示开始；转动过程中绿色 2 闪表示还需要更多方向覆盖，快闪表示数据已足够；绿色 4 闪表示完成 |
| 陀螺仪灵敏度自动校准 | 慢闪表示先保持静止；快闪表示可以开始按指定轴旋转；常亮表示正在记录旋转；绿色 4 闪表示保存完成 |
| 温度校准加热 | 升温阶段使用慢呼吸，并按本次起始温度到目标温度从青色渐变到橙红色；保温/稳定阶段使用同一渐变色快呼吸；青色错误组表示检测到运动暂停；紫色慢呼吸表示开环/调试状态；完成为绿色 4 闪，停止/超时为绿色 2 闪，异常为红色 3 闪 |

进行校准时，尽量不要同时操作按钮或插拔电源。温度校准加热默认要求外部供电，并且此板子的加热控制由 `imu-heater` PWM 和 `heat-en-gpios` 支持。
